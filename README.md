## 🚀 Quick Start

### Prerequisites
- Modern web browser with WebRTC support
- Webcam/camera access
- Good lighting for hand detection

### Installation
1. Clone or download the repository
2. Open `cats_cradle.html` in your web browser
3. Allow camera permissions when prompted
4. Start playing!

```bash
# Clone the repository
git clone <repository-url>
cd Cats_cradle

# Open in browser
open cats_cradle.html
```

## 🎮 How to Play

### Basic Controls
- **Camera**: Position yourself in front of the camera
- **Hands**: Use both hands for gesture recognition
- **Mode Selection**: Click mode buttons at the bottom
- **Difficulty**: Adjust difficulty level as needed

### Game Modes Explained

#### 🔗 STRINGS Mode
- Touch same fingertips together
- Create neon string connections
- Score points for successful connections
- Build combos for higher scores

#### 🎯 CATCH DOT Mode
- Moving dots appear on screen
- Use hand movements to catch them
- Quick reactions earn bonus points
- Track your fastest reaction time

#### 🪞 MIRROR Mode
- Match the displayed mirror pose
- Hold poses accurately for points
- Precision and timing matter
- Perfect matches give bonus scores

#### ❄️ FREEZE Mode
- Hold specific hand positions
- Maintain poses for required duration
- Stability and control are key
- Longer holds = higher scores

## 🎯 Scoring System

- **Base Points**: Earned for successful actions
- **Combo Multiplier**: Consecutive successes increase score
- **Speed Bonus**: Faster reactions = more points
- **Accuracy Bonus**: Precise movements earn extra points
- **Time Bonus**: Remaining time adds to final score

## 🐛 Troubleshooting

### Camera Issues
- Check browser permissions
- Ensure camera is not used by other apps
- Try refreshing the page
- Check camera drivers

### Performance Issues
- Close other browser tabs
- Ensure good lighting
- Lower browser zoom level
- Update graphics drivers

### Detection Problems
- Improve lighting conditions
- Move closer/further from camera
- Ensure hands are clearly visible
- Avoid busy backgrounds
